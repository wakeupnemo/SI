## Known limitations

- This is a verified first vertical slice plus package/round/theme safe typed fields and complete hierarchy structural commands, metadata, package logo and quality control, complete text-answer lists, dedicated non-text answer inspectors with image-backed point picking, complete recursive parameter editing, scenario/content editing with direct media selection, settings, native clipboard, complete recovery persistence/management, full-workspace flat layout/scale presentation, isolated external flat drops, typed media-library management, validation/statistics navigation, verified text conversion/save/reload with structural SPARD editing, native Linux text-question preview, and release packaging foundations, not full parity. Native drag/drop acceptance, package-media/replay preview parity, native SPARD correction visual acceptance, and advanced import/export remain incomplete. Explicit parameter type conversion intentionally replaces incompatible value structure, but is one undoable user action and never occurs during load, display, rename, or save.
- Recovery retention is deliberately conservative: only the latest validated generation is kept per document; superseded generations are removed after pointer commit, and a successful canonical save, approved close, or explicit discard removes the recovery identity. Valid stale snapshots and malformed entries are not age-pruned silently because doing so could destroy the only recoverable user data.
- Language changes intentionally apply after restart and communicate that boundary. System/light/dark selection is live and persisted, but visual theme snapshots and a macOS runtime Command-key receipt remain pending.
- The retained question player now has verified native Linux text and embedded-image receipts plus automated available/unavailable backend gates.
