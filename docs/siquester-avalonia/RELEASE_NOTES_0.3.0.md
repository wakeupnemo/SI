# SIQuester Cross-Platform 0.3.0

SIQuester Cross-Platform is now available for Linux, macOS, and Windows.

## What's new

- Drag themes to reorder them or move them between rounds.
- Drag questions to reorder them or move them between themes.
- Continue editing after a move with the moved item selected and full undo/redo support.
- Create, edit, preview, save, and reopen SIQ packages in the cross-platform editor.
